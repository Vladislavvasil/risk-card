# Карточка риска: Синдром больного здания

## О проекте

Одностраничный адаптивный сайт-визитка на тему «Синдром больного здания».
Проект сделан как учебная работа по HTML, CSS и JavaScript и состоит из двух
страниц:

- `index.html` — обзор: что такое синдром больного здания, его симптомы,
  причины, рекомендации по улучшению воздушной среды, параметры микроклимата
  и разделы «До события», «Во время события», «После события»,
  «Когда обращаться в официальную службу».
- `checklist.html` — отдельная страница с интерактивным чек-листом из восьми
  пунктов. По мере отметок обновляется прогресс-бар, а по нажатию
  кнопки «Показать результат» выводится учебная оценка риска: низкий,
  средний или высокий уровень с кратким пояснением и списком того,
  что сделать в первую очередь.

Дизайн: тёмная градиентная шапка с декоративной SVG-иллюстрацией,
светлые «плавающие» карточки с анимацией появления при прокрутке.
Интерфейс адаптируется под компьютер и телефон, все элементы доступны
с клавиатуры, фокус виден.

## Как запустить

Скачать файлы проекта и открыть `index.html` в браузере.
Все четыре файла (`index.html`, `checklist.html`, `styles.css`, `main.js`)
должны лежать в одной папке. Никаких сборок, установок и интернета
не требуется.

## Ограничения

Сайт не ставит диагнозы и не определяет наличие заболевания.
Оценка риска в чек-листе — **учебная**: она лишь показывает, насколько
полно выполнены рекомендации из источников, и не учитывает площадь
помещения, число людей, климат, сезон и индивидуальные особенности
здоровья. Никакие измерения (уровень CO₂, влажность, температура)
сайт не производит — только сверяет с рекомендованными значениями.
Замена консультации специалиста и обращение в официальные службы
страница не заменяет. Телефоны, адреса и нормативные значения
на странице намеренно не публикуются.

## Применение нейросети

- **Задача для помощника:** написать разметку и логику учебного
  одностраничника по готовому набору фактов, оформить его в современном
  стиле (вдохновлялись референсами Risolut, Re-action, Cutwoodshop),
  а затем вынести чек-лист на отдельную страницу и добавить простую
  оценку риска.
- **Существенный запрос:** «Создай одностраничный адаптивный сайт на тему
  "Синдром больного здания"… сделай отдельные разделы "До события",
  "Во время события", "После события" и "Когда обращаться в официальную
  службу"… добавь полезный интерактивный чек-лист действий на JavaScript…
  верни результат тремя отдельными блоками кода строго в таком порядке:
  index.html, styles.css, main.js.»
- **Проверка результата:** все факты (симптомы, причины, рекомендации,
  параметры микроклимата, факт 1984 года, «в 9 раз» и «в 5 раз»)
  сверялись с двумя ссылками Роспотребнадзора, приведёнными выше.
  Код проверялся вживую: страница открывалась локально в браузере,
  проверялись адаптив (сужение окна до ~360 и ~600px), работа чек-листа
  мышью и клавиатурой (`Tab`, `Space`, `Enter`), видимость фокуса,
  обновление прогресса и корректность выдачи уровня риска на разных
  наборах отметок. Искались и удалялись вставки через `innerHTML`
  в местах, где данные приходят из переменных.
- **Самостоятельные исправления:** вручную расширен контейнер
  (`--max-width` увеличен с 1080px), уменьшена высота шапки, шапка
  переведена в двухколоночный вид с SVG-иллюстрацией, добавлена
  анимация появления карточек, пороговые значения уровней риска
  вынесены в переменные `LEVEL_LOW` и `LEVEL_MID`, добавлена
  отдельная подсказка, если пользователь нажал «Показать результат»
  без единой галочки.
- **Не передавались модели:** персональные данные, пароли и закрытая
  информация.
